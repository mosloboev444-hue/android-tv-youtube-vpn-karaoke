# Если что-то не работает

Сначала смотрите логи:

```powershell
adb -s 192.168.1.50:5555 logcat -s VpnGate
```

| Симптом | Что проверить |
|---|---|
| YouTube открывается, VPN не включается | Включена ли служба: `adb shell settings get secure enabled_accessibility_services`. Должен быть `com.gathin.vpngate/...`. Если пусто — выполните `app/install.ps1` ещё раз. |
| В логе `connect button not found` | Юбуст обновился и поменял текст/разметку. Откройте Юбуст вручную и проверьте, что кнопка называется «Подключить». Резервный поиск большой кнопки справа должен сработать; если нет — поправьте текст в `clickConnectButton()` и пересоберите APK. |
| Юбуст открылся, но кнопка не нажалась | Проверьте, что Юбуст не показывает экран логина/оплаты. Войдите в аккаунт и выберите режим «Только YouTube» один раз вручную. |
| VPN поднялся, YouTube пишет «Нет подключения к сети» | Сервер Юбуста недоступен или туннель «залип». Откройте Юбуст, отключите/подключите VPN, проверьте `ip addr show tun0`. При необходимости смените сервер. |
| YouTube вернулся, но видео не грузится | Проверьте, что Юбуст в режиме «Только YouTube»; проверьте `tun0`; откройте YouTube заново. |
| После перезагрузки ТВ ничего не работает | Служба доступности могла не подняться. Проверьте `dumpsys accessibility`; включите заново `app/install.ps1`. VPN после перезагрузки всегда выключен — это нормально. |
| Плитки «Караоке!!!» нет | Установлен обычный CleanYourTV без патча. Поставьте `apk/CleanYourTV-Karaoke-3.2.apk` или соберите форк (см. `launcher/README.md`). |
| Огонь на плитке не двигается | Проверьте, что это именно пропатченный лаунчер и `fire_app` указывает на `com.gathin.vpngate`. Анимация останавливается в `onPause`; на главном экране должна идти. |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Лаунчер/приложение подписаны другим ключом. Пересоберите своим ключом или удалите старую версию (`adb uninstall ...`), затем поставьте снова. |
| `adb: device not found` | `adb connect <ip>:5555`, подтвердите запрос на ТВ, проверьте, что отладка по сети включена. |
| Служба доступности сама выключается | Некоторые прошивки сбрасывают `enabled_accessibility_services` после перезагрузки. Включите заново или добавьте в автозапуск через ADB. |

## Как проверить, что туннель есть

```powershell
adb -s 192.168.1.50:5555 shell "ip addr show tun0"
```

Ожидаемо: интерфейс `tun0` с `inet 172.x.x.x/32`.

## Как посмотреть, какое окно в фокусе

```powershell
adb -s 192.168.1.50:5555 shell "dumpsys activity activities | grep topResumedActivity"
```

## Полный сброс

```powershell
adb -s 192.168.1.50:5555 shell "settings put secure enabled_accessibility_services ''"
adb -s 192.168.1.50:5555 shell "settings put secure accessibility_enabled 0"
adb -s 192.168.1.50:5555 uninstall com.gathin.vpngate
```

Затем установите заново.
