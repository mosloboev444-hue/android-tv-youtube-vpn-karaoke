## Как записано

С реального телевизора, через `adb shell screenrecord`; действия — `adb shell input`. Для «ДО»
временно возвращался старый лаунчер и выключалась служба доступности, для «ПОСЛЕ» — новый лаунчер и
включённая служба. Монтаж — ffmpeg: вертикальный холст, подписи, карточки, сгенерированный бит.

Личный e-mail в кадре Юбуста заблюрен. Сырые записи экрана в репозиторий не входят — в них виден
адрес аккаунта.
